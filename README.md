# Гранитная мастерская «ГраалЬ» — сайт

Переделка сайта [graalgranit.tb.ru](https://graalgranit.tb.ru/) для запуска на новом хостинге с новым доменом.

**Стек:** чистый HTML + CSS + JS, без сборки и зависимостей. Шрифты лежат локально, внешних запросов нет — сайт одинаково быстро открывается на любом хостинге (nginx, Apache, shared hosting, GitHub Pages, S3/статика).

## Быстрый старт

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

И просто открыть `index.html` в браузере — всё работает и без сервера.

## Структура

```
index.html            главная (все секции)
privacy.html          политика обработки персональных данных
404.html              страница 404
assets/
  css/style.css       стили, адаптив, анимации
  js/main.js          меню, фильтр каталога, форма, появление блоков
  fonts/              Cormorant Garamond + Manrope (кириллица, woff2)
  img/                hero, фактура гранита, мастерская
  img/catalog/        6 карточек каталога
favicon.svg
robots.txt
sitemap.xml
```

## Чек-лист перед запуском

1. **Заменить домен** в `sitemap.xml`, `robots.txt`, `og:image` и в JSON-LD (`url`, `image`, `logo`) внутри `index.html` — сейчас там `example.com` и относительные пути. Добавить `<link rel="canonical">`.
2. **Подставить реальные фото работ** — сейчас в `assets/img/catalog/` сгенерированные иллюстрации форм. Положите фото с теми же именами (или поменяйте пути в `index.html`). Реальные фотографии повышают доверие сильнее любого дизайна.
3. **Добавить цены**, если готовы их публиковать: секция `#prices` уже свёрстана, достаточно вписать цифры в список факторов или отдельным блоком.
4. **Проверить реквизиты**: при желании добавить ИНН/ОГРН в подвал — сейчас их нет, чтобы не публиковать выдуманные данные.
5. **Яндекс.Карты**: ссылки «открыть на карте» уже ведут на поиск по адресу. Если нужно — вставьте iframe виджета Яндекс.Карт вместо ссылок.
6. **Аналитика**: счётчиков нет. Если нужен Яндекс.Метрика или GA4 — добавьте скрипт перед `</head>` и обновите политику (сейчас в ней честно написано, что аналитики и cookie нет).
7. **Форма**: сейчас открывает WhatsApp с готовым текстом. Для отправки на почту/CRM замените обработчик `submit` в `assets/js/main.js` (пример с `fetch` на ваш endpoint — несколько строк).
8. **Проверить телефоны и почту** перед публикацией — они взяты со старого сайта как есть.

## Как заменить фото

Каталог: `assets/img/catalog/vertical.jpg`, `double.jpg`, `carved.jpg`, `complex.jpg`, `fence.jpg`, `improvement.jpg` — соотношение 4:3, достаточно ширины 900 px.

Главное фото: `assets/img/hero.jpg` (широкое, 16:9, от 1400 px).

Оптимизация без потери качества:

```bash
python3 -m pip install Pillow
python3 -c "from PIL import Image; im=Image.open('photo.jpg'); im.thumbnail((900,900)); im.save('assets/img/catalog/vertical.jpg', quality=80, optimize=True, progressive=True)"
```
